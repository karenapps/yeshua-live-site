# Site YESHUA LIVE

Página estática de apresentação em português.

## Publicar no GitHub Pages
1. Crie um repositório público chamado `yeshua-live-site`.
2. Envie o arquivo `index.html` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/(root)`, depois clique em **Save**.
6. Aguarde a publicação. O endereço será `https://SEU-USUARIO.github.io/yeshua-live-site/`.

Troque `SEU-USUARIO` pelo nome da sua conta GitHub. Não coloque tokens, senhas ou chaves neste repositório.
